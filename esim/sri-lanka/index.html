Before you buy

Sri Lanka plans we checked start at $0.59 from Airalo, Holafly, Saily, Nomad, Ubigi, Maya Mobile, Roamless, GigSky, Yesim. Named networks include Hutch, 4G/5G, 4G, 5G. 51 plans list 5G. 1 publish a slower speed after a fair-use cap. Checked 28 Oct 2026.

Common questions

Do Sri Lanka eSIM plans include calls and SMS?

21 of the 107 plans we list include calls or SMS. The rest are data-only. Use the Calls icon to filter.

Can I use a hotspot in Sri Lanka?

55 plans say hotspot or tethering is allowed. Others don’t say, so the Hotspot filter only keeps the ones that do.

When does a Sri Lanka eSIM activate?

20 plans start when the eSIM first joins a local network, not when you pay. Install on Wi-Fi before you fly.

Does my phone support eSIM?

iPhone XR and later support eSIM, except models sold in mainland China. Many recent Galaxy and Pixel phones do too, if they are unlocked. Use the compatibility checker and look for Add eSIM in settings.
