Before you buy

Netherlands plans we checked start at $0.53 from Airalo, Holafly, Nomad, Ubigi, Saily, Maya Mobile, Roamless, Yesim, GigSky. Named networks include KPN, 4G, 4G/5G, 5G. 47 plans list 5G. 2 publish a slower speed after a fair-use cap. Checked 28 Oct 2026.

Common questions

Do Netherlands eSIM plans include calls and SMS?

12 of the 110 plans we list include calls or SMS. The rest are data-only. Use the Calls icon to filter.

Can I use a hotspot in Netherlands?

59 plans say hotspot or tethering is allowed. Others don’t say, so the Hotspot filter only keeps the ones that do.

When does a Netherlands eSIM activate?

39 plans start when the eSIM first joins a local network, not when you pay. Install on Wi-Fi before you fly.

Does my phone support eSIM?

iPhone XR and later support eSIM, except models sold in mainland China. Many recent Galaxy and Pixel phones do too, if they are unlocked. Use the compatibility checker and look for Add eSIM in settings.
