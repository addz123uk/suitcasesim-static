Common questions

Do New Caledonia eSIM plans include calls and SMS?

None of the New Caledonia plans in this import include a phone number, calls, or SMS. Messaging apps use the data allowance.

Can I use a hotspot in New Caledonia?

15 plans say hotspot or tethering is allowed. Others don’t say, so the Hotspot filter only keeps the ones that do.

When does a New Caledonia eSIM activate?

Activation rules aren’t stated on every plan. Install on Wi-Fi, then turn on data roaming only for the travel line after you land.

Does my phone support eSIM?

iPhone XR and later support eSIM, except models sold in mainland China. Many recent Galaxy and Pixel phones do too, if they are unlocked. Use the compatibility checker and look for Add eSIM in settings.
