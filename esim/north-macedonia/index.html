Before you buy

North Macedonia plans we checked start at $0.53 from Airalo, Holafly, Nomad, Ubigi, Saily, Roamless, GigSky, Yesim. Named networks include A1, Makedonski Telekom, 4G, 4G/5G, 5G. 23 plans list 5G. 1 publish a slower speed after a fair-use cap. Checked 28 Oct 2026.

Common questions

Do North Macedonia eSIM plans include calls and SMS?

6 of the 73 plans we list include calls or SMS. The rest are data-only. Use the Calls icon to filter.

Can I use a hotspot in North Macedonia?

29 plans say hotspot or tethering is allowed. Others don’t say, so the Hotspot filter only keeps the ones that do.

When does a North Macedonia eSIM activate?

26 plans start when the eSIM first joins a local network, not when you pay. Install on Wi-Fi before you fly.

Does my phone support eSIM?

iPhone XR and later support eSIM, except models sold in mainland China. Many recent Galaxy and Pixel phones do too, if they are unlocked. Use the compatibility checker and look for Add eSIM in settings.
