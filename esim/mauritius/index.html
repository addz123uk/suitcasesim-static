Common questions

Do Mauritius eSIM plans include calls and SMS?

None of the Mauritius plans in this import include a phone number, calls, or SMS. Messaging apps use the data allowance.

Can I use a hotspot in Mauritius?

41 plans say hotspot or tethering is allowed. Others don’t say, so the Hotspot filter only keeps the ones that do.

When does a Mauritius eSIM activate?

10 plans start when the eSIM first joins a local network, not when you pay. Install on Wi-Fi before you fly.

Does my phone support eSIM?

iPhone XR and later support eSIM, except models sold in mainland China. Many recent Galaxy and Pixel phones do too, if they are unlocked. Use the compatibility checker and look for Add eSIM in settings.
