Before you buy

Common questions

Do Qatar eSIM plans include calls and SMS?

6 of the 85 plans we list include calls or SMS. The rest are data-only. Use the Calls icon to filter.

Can I use a hotspot in Qatar?

38 plans say hotspot or tethering is allowed. Others don’t say, so the Hotspot filter only keeps the ones that do.

When does a Qatar eSIM activate?

30 plans start when the eSIM first joins a local network, not when you pay. Install on Wi-Fi before you fly.

Does my phone support eSIM?

iPhone XR and later support eSIM, except models sold in mainland China. Many recent Galaxy and Pixel phones do too, if they are unlocked. Use the compatibility checker and look for Add eSIM in settings.
